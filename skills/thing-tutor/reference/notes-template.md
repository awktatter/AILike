# Learner-Notes Template

Persisted per topic at `~/.llm-learning/<topic-slug>.md` (outside the skills
repo, so progress is private and never committed). On revisit, the skill reads
this file to resume at the right level. Fill only what's known; leave the rest.

```markdown
# Learning Notes: <Concept>

## Learner profile
- Assessed level: working | proficient | advanced | staff
- Goal: <what they want to be able to do with this>
- Relevant background: <experience that shapes how to teach this>

## Progress
- First studied: <YYYY-MM-DD>
- Last revisited: <YYYY-MM-DD>
- Sessions: <n>
- Current mastery: working | proficient | advanced | staff

## Covered
- <subtopic> — <mastery / confidence>

## Open gaps & misconceptions
- <specific gap or wrong belief to revisit>

## Next steps
- <what to tackle in the next session>

## Spaced revisit
- Next review: <YYYY-MM-DD> — <why then>
```

Guidance:
- Keep entries terse and specific ("confuses image vs container lifecycle"),
  not vague ("needs more practice") — the point is to resume precisely.
- Update `Last revisited`, `Sessions`, and `Current mastery` every session.
- Set `Next review` sooner for shaky topics, later for solid ones (spaced
  repetition).
